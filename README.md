# Garimpei Pra Você

Painel pessoal para divulgar produtos da Shopee e acompanhar resultados.

- Este repositório é **público** e contém **apenas o código** do painel (`index.html`).
- Produtos, legendas, links afiliados e relatórios **não ficam aqui**: ficam no navegador e numa planilha privada do seu Google Drive.
- Nenhuma senha, token ou chave de API deve ser colocada neste repositório.
- Nunca envie para cá backups (`.json`), exportações (`.csv`) ou prints com dados pessoais.

Guias de configuração: pasta `docs/`.
