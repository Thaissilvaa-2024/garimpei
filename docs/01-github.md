# Etapa 1: publicar no GitHub Pages (gratuito)

1. Crie uma conta em github.com (plano Free).
2. Clique em **New repository**. Nome sugerido: `garimpei`. Marque **Public** (no plano Free o GitHub Pages exige repositório público). Marque **Add a README file** e crie.
3. Em **Add file > Upload files**, envie `index.html` e a pasta `docs/`. Clique em **Commit changes**.
   (Não envie backups, CSVs nem prints.)
4. Vá em **Settings > Pages**. Em *Build and deployment*, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)**, e salve.
5. Aguarde 1 a 3 minutos. O endereço será `https://SEU-USUARIO.github.io/garimpei/`.
6. Abra o endereço no notebook e no celular. Na primeira vez os dados estarão vazios: importe seu backup JSON em **Dados e backup**.

Anote seu endereço **de origem**: `https://SEU-USUARIO.github.io` (sem `/garimpei`). Será usado na etapa 2.

Observação: os dados de cada aparelho ficam no navegador dele. O celular só verá seus produtos depois da sincronização (etapa 2).
